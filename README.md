# Computer Networks Project

## 📌 Objective
To design and demonstrate a computer network using IP addressing, switching, and routing concepts.

## 🧩 Network Components
- PCs
- Switch
- Router

## ⚙️ Features
- IP Configuration
- Default Gateway setup
- MAC Address identification
- Switch port status monitoring
- Router interface configuration
- VLAN setup (basic)
- Packet transmission testing

## 🎥 Demo Video
The video demonstrates:
- Network topology
- IP configuration
- Switch and router status
- Packet flow between devices

## 🛠️ Tools Used
- Cisco Packet Tracer

## 📈 Conclusion
The network successfully demonstrates communication between devices and basic networking concepts.
